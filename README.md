# Barnbound

Horse shipping desk. Request a quote from a phone: pickup, delivery, horses, and a way to reach you. The price is on the page before you send it, and the haul stays on the board.

A quote is estimated road miles between hubs, plus the rig, layovers, and special care. Sample hauls are marked Sample. Requests you send are saved in this browser.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:4327](http://localhost:4327).

## Test

```bash
npm test
```
